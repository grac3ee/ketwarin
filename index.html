Web Application สำหรับร้านขายของขวัญออนไลน์ รองรับการทำงานทั้งฝั่งลูกค้าและผู้ดูแลระบบ ตั้งแต่เลือกสินค้า สั่งซื้อ ชำระเงิน ไปจนถึงจัดการสินค้า โปรโมชั่น สต็อก และคำสั่งซื้อ

ปัญหา

กระบวนการขายออนไลน์มีหลายขั้นตอน ทั้งการเลือกสินค้า การสั่งซื้อ การชำระเงิน สต็อก และการจัดการหลังบ้าน จึงต้องมีระบบที่เชื่อม Workflow ให้ทำงานต่อเนื่องและตรวจสอบได้

สิ่งที่สร้าง

พัฒนาเว็บไซต์ร้านของขวัญออนไลน์ พร้อมระบบลูกค้าและ Admin สำหรับจัดการสินค้า โปรโมชั่น คำสั่งซื้อ และข้อมูลที่เกี่ยวข้องกับการขาย

✦ บทบาทของฉัน

วิเคราะห์ Requirement และ Workflow วางโครงสร้างระบบ พัฒนาหน้าเว็บไซต์และฟังก์ชันหลัก รวมถึงเชื่อมการทำงานกับฐานข้อมูล

สิ่งที่ได้เรียนรู้

เข้าใจกระบวนการพัฒนา Web Application แบบครบ Workflow ตั้งแต่การวิเคราะห์ระบบ การออกแบบหน้าเว็บ การตรวจสอบข้อมูล ไปจนถึงการเชื่อมฐานข้อมูลและจัดการสถานะคำสั่งซื้อ

02 / AI PROJECT

LawBot

ระบบผู้ช่วยด้านกฎหมายด้วย RAG

ChatbotRAGLegal Data
AI • RAG • QUESTION ANSWERING

Thai Legal Assistant Chatbot สำหรับช่วยค้นและสรุปข้อมูลกฎหมายจากชุดข้อมูลที่กำหนด โดยเชื่อม Front-end กับ FastAPI Backend และใช้แนวคิด Retrieval-Augmented Generation เพื่อสร้างคำตอบที่อ้างอิงบริบทจากข้อมูล

ปัญหา

ข้อมูลกฎหมายมีรายละเอียดมากและใช้ภาษาที่เข้าใจยาก ผู้ใช้ทั่วไปจึงอาจค้นหาข้อมูลที่เกี่ยวข้องกับคำถามของตนเองได้ไม่สะดวก

สิ่งที่สร้าง

พัฒนา Chatbot ที่รับคำถามจากผู้ใช้ ค้นข้อมูลที่เกี่ยวข้องจาก Dataset ส่งผ่าน RAG Pipeline และแสดงคำตอบพร้อมสรุปภาษาที่อ่านเข้าใจง่ายขึ้น

✦ บทบาทของฉัน

วิเคราะห์โครงสร้าง Chatbot ออกแบบ Workflow การถาม–ตอบ พัฒนาและทดสอบระบบค้นหาคำตอบ รวมถึงออกแบบการนำเสนอผลลัพธ์ให้เหมาะกับผู้ใช้งาน

สิ่งที่ได้เรียนรู้

เรียนรู้การเชื่อม Front-end, Backend และ RAG เข้าด้วยกัน รวมถึงการออกแบบคำตอบสำหรับข้อมูลที่ต้องสื่อสารอย่างระมัดระวัง เช่น การแสดง Disclaimer และสรุปภาษาคนทั่วไป

03 / MANAGEMENT SYSTEM

Fix Up

ระบบแจ้งซ่อมและติดตามสถานะงาน

UserTechnicianAdmin
MANAGEMENT SYSTEM • REST API

ระบบบริหารจัดการงานแจ้งซ่อมสำหรับผู้ใช้งาน ช่าง และผู้ดูแลระบบ ช่วยรวบรวมคำขอซ่อมไว้ในระบบเดียวและติดตามสถานะงานตั้งแต่แจ้งปัญหาจนถึงการดำเนินงานของช่าง

ปัญหา

การแจ้งซ่อมผ่านช่องทางที่กระจัดกระจายทำให้ติดตามงานยาก ข้อมูลอาจตกหล่น และผู้แจ้งไม่เห็นสถานะการดำเนินงานที่ชัดเจน

สิ่งที่สร้าง

พัฒนาระบบแจ้งซ่อมที่มีหน้า Dashboard การจัดการคำขอซ่อม การติดตามสถานะ และการเชื่อมข้อมูลระหว่าง Front-end, API และฐานข้อมูล

✦ บทบาทของฉัน

วิเคราะห์ความต้องการและ Workflow ของผู้ใช้แต่ละบทบาท ออกแบบหน้าจอและโครงสร้างระบบ รวมถึงพัฒนาการเชื่อมต่อ API และฐานข้อมูล

สิ่งที่ได้เรียนรู้

เข้าใจการออกแบบระบบที่มีหลายบทบาท การจัดการสถานะงาน และการเชื่อม React Front-end กับ REST API และฐานข้อมูลให้ทำงานเป็น Workflow เดียวกัน
